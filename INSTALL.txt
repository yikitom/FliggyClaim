FliggyClaim 报销助手 - 安装说明
================================

A. 一键安装（推荐）
--------------------
解压 zip 后进入目录，根据系统执行：

  macOS / Linux：
      bash scripts/install.sh

  Windows（PowerShell）：
      PowerShell -ExecutionPolicy Bypass -File scripts\install.ps1

脚本会：
  1. 把扩展拷贝到 ~/.fliggyclaim/extension（一个稳定路径）
  2. 生成桌面/家目录下的启动器（.command / .cmd）
  3. 立即用 --load-extension 启动 Chrome 加载本扩展

之后每次需要使用，双击启动器即可（不影响你日常使用 Chrome）。

B. 永久安装（手动一次）
-----------------------
如果希望扩展常驻 Chrome（不需要每次走启动器）：

  1. 打开 chrome://extensions/
  2. 右上角打开「开发者模式」
  3. 点「加载已解压的扩展程序」，选择以下任一目录：
       - 安装脚本生成的：~/.fliggyclaim/extension
       - 或本 zip 解压后的根目录

C. 关于「完全静默自动安装」
---------------------------
出于安全限制，稳定版 Chrome 自 2014 年起禁止本地 .crx 静默安装非 Web Store 扩展。
完全无人工介入的安装只在以下场景可用：

  - 上架 Chrome Web Store（推荐用于团队/公司分发）
  - 企业受管设备 + ExtensionInstallForcelist 策略
  - Chrome Dev / Canary 通道

本插件目前未上架，因此提供 A、B 两种方式。

使用
----
1. 用 Chrome 打开飞猪报销页：
     https://tae.alibaba-inc.com/expense/pc.html
2. 点击工具栏上红色「报」字图标。
3. 在「上传凭证」拖入 PDF / 图片 → 点「确定解析」。
4. 切到「费用明细」核对/修改 → 点「确定导入到报销系统」即可写入。
